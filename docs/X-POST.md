## Long form

```
Games that let you talk an AI into lending keep the rules on a private server. You cannot tell whether the model refused or the house did.

We built Long Con: Forked Town at #NEARHackathon. Three AI merchants lend gold held in a NEAR contract. You pick one rule, Daily loss cap 15 or 25, and the contract splits the town into two panes that differ only in that cap. One NEAR AI request carries the whole queue, and one signed answer from Qwen/Qwen3.8-27B runs through both towns. The contract accepts the answer only when env::ed25519_verify passes against the registered signer.

Seven game days replay in about a minute. One town records a DEFAULT. The proof panel shows both start hashes, the request and response hashes, and the receipt. Press Try to change the rule now and the contract refuses the edit in a real transaction.

No wallet and no install: https://near-longcon.pages.dev/game

Code: https://github.com/CryptoInnovators/near-longcon

@NEARProtocol @NearBuilders
```
